Install the web UI from this device

Pick the SPIFFS image (storage.bin) built from firmware/webui/. It is written straight into the storage partition, then the box reboots. No internet needed.

Or build and flash it over USB

cp -r your-webui/* firmware/webui/
idf.py build
idf.py -p /dev/cu.usbmodem1101 storage-flash

The app image and the web UI live in separate partitions, so reflashing the UI never touches the firmware, your stored signals or your automations.
